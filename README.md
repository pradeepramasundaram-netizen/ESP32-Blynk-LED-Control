# ESP32 Blynk LED Control

This project controls an LED using an ESP32 and the Blynk IoT platform.

## Components

- ESP32 DevKit V1
- LED
- Resistor
- USB cable

## Software

- Arduino IDE
- Blynk
- Arduino Framework
